# Pattern library and opportunity scoring

Recurring patterns behind viral and successful Roblox games, described as mechanics so they can be reused in original games. Which ones are hot changes month to month: confirm with live charts before recommending one.

## Loop patterns

| Pattern | Core loop | Why it works | Monetizes through | Watch out for |
|---|---|---|---|---|
| **Steal / raid** | build up a base or collection → others can steal it → defend, steal back | Loss aversion and revenge create drama; every server becomes a story; great clips | locks/shields, speed, extra slots, luck, revenge tools | Frustration for new players (protection windows), exploit target (server authority needed) |
| **Collect & rarity** | earn → open eggs/crates/spins → rarer collectibles → stronger or flashier | Variable rewards; show-off value; trading | luck boosts, extra slots, auto-open, currency packs | Odds disclosure rules, inflation, power creep |
| **Grow & tend (timers)** | plant/place → wait → harvest/sell → better seeds | Return hooks built in (things finish while away); calm and casual | growth speed, extra plots, rare seeds, weather/event boosts | Needs events and mutations to stay fresh; theft or trading adds spice |
| **Train a stat** | train (click, treadmill, lift) → stat grows → reach new areas/beat bigger things | Dead simple; constant number growth; works on any device | multipliers, auto-train, pets/companions with bonuses | Shallow without a meta goal (zones, rebirth, competition) |
| **Throw / launch / distance** | power up → launch something → distance = money → upgrade | Physical, funny, instantly readable in a thumbnail | power multipliers, better projectiles, zones | Needs varied destinations and rewards per distance |
| **Physics toy / ragdoll sandbox** | mess around with physics → chaos → laugh | Zero learning curve, highly shareable | cosmetics, tools, private servers | Weak retention unless goals, challenges or progression are added |
| **Survive the X** (rounds) | round starts → random threat → survive → reward | Fresh every round, great with friends, short sessions | revives, perks, cosmetics, character unlocks | Waiting time, snowballing, needs content variety |
| **Asymmetric chase (1 vs many)** | hunter vs survivors with objectives | Tension, role variety, streamer-friendly | character/ability unlocks, skins, emotes | Balance, matchmaking, toxic behavior |
| **Build then test** | build something (bridge, boat, house) → physics test → reward | Creativity plus spectacle; every result different | parts, materials, plots, cosmetics | Build tools must work on touch screens |
| **Tower / obby with social chaos** | climb → others can grab/push/troll → fall → retry | Laughs and rivalry; easy to understand | skips, gravity coils, troll tools, checkpoints | Frustration tuning, griefing limits |
| **Skill PvP** (shooter, fighting, sports) | match → mastery → rank | Mastery and competition hold players for months | skins, weapon cases, battle passes, emotes | High polish bar, server authority for fairness, matchmaking |
| **Unit collection + strategy** (tower defense, auto-battlers) | summon units → beat waves/stages → better units | Collection plus strategy depth | summons, luck, slots, battle passes | Gacha policy and odds rules, content-heavy |
| **Tycoon / idle** | buy buttons → base builds itself → income → rebirth | Visible growth, low effort, offline income | 2× income, auto-collect, VIP areas | Walking between buttons, flat late game |
| **Life sim / roleplay** | houses, jobs, vehicles, social roleplay | Self-expression and friends | houses, vehicles, cosmetics, VIP | Empty servers, needs constant content |
| **Gather / fish / mine with zones** | gather → sell → better tool → new zone with rarer catches | Calm loop with rarity spikes | luck, better tools, storage, auto-sell | Repetition; needs events and rare finds |

Many breakouts combine two: collect & rarity + steal, grow & tend + steal, train a stat + throw/launch, survive the X + build.

## Viral and distribution patterns

- **Readable title formula**: "[Verb] a [Noun]", "[Noun] Simulator", "Survive the [X]". Players and algorithms understand it instantly. Update tags like `[UPD]` and an emoji signal activity.
- **"How to play" description**: 4–8 emoji lines that spell out the loop. Reads in seconds and doubles as search text.
- **Thumbnail as the verb's best moment**: exaggerated reaction, huge scale, rare item, crowd.
- **Small servers for interaction-driven loops** (5–10 players): fast server fill, constant contact with others, every server has drama.
- **Scheduled updates and countdowns**: a fixed weekly update time, an in-game countdown, and a "press Notify" prompt in the description. Players gather for the drop, which spikes concurrent users and chart rank.
- **Live events**: limited-time weather, mutations, bosses or the developers appearing in servers with special powers. Fear of missing out drives return visits.
- **Friend mechanics**: rewards for playing with friends, invite prompts at natural moments, co-op goals, stealing from or helping friends.
- **Clip-ability**: moments worth recording (a rare drop, a dramatic steal, chaos physics, a huge transformation). Content creators pick games that produce them.
- **Fast follow on a wave**: when a new loop breaks out, dozens of games use it within days. Early movers with a clear, original theme and good polish capture most of the wave; late, near-identical entries rarely do.
- **Low-end phone performance**: a large share of the audience plays on entry-level phones; games that load fast and run smoothly there keep those players.

## Opportunity scorecard

Score 1 (bad) to 5 (good). Weight by the team's situation; defaults below.

| Criterion | Weight | Ask |
|---|---|---|
| Demand | 3 | How many players does this loop/genre hold across the top charts? |
| Momentum | 2 | Is it growing (trending, up-and-coming, snapshot deltas) or fading? |
| Competition | 2 | How many strong games, how polished, how old? Is the leader neglected? |
| Differentiation | 3 | Do we have a twist players will see in the thumbnail? |
| Build cost fit | 3 | Can this team ship a good MVP in its timeframe? |
| Time sensitivity | 1 | If it's a wave, can we ship before it peaks? (Low score if not.) |
| Monetization fit | 2 | Does the loop support fair passes/products like the leaders'? |
| Retention potential | 2 | Is there a meta loop and return reason, or only a one-session hook? |
| Risk | 1 | IP closeness, policy issues (paid random items, age ratings), exploit exposure |

Total = Σ score × weight (max 95). Present the top two or three options as a table with one line of reasoning per cell, then recommend one.

## The remix formula

**Proven loop + one strong visible twist + better execution in one area the leaders neglect.**

Twist sources:
- **Theme swap**: same loop, a world or fantasy no one has used for it (with original characters and art).
- **Verb twist**: the same progression, but a different action (throw instead of click, build instead of buy).
- **Social twist**: add stealing, co-op, trading or competition to a loop that lacks it.
- **Audience shift**: a loop proven with one audience, rebuilt for another (calmer, scarier, more competitive, younger, older, a country or language underserved).
- **Platform focus**: the best version on phones or consoles when leaders are PC-first.
- **Session shift**: a long-session loop compressed into 5-minute rounds, or vice versa.

Execution areas leaders often neglect: first-minute onboarding, phone UI, performance on low-end devices, update cadence, fairness for free players, anti-exploit protection.
