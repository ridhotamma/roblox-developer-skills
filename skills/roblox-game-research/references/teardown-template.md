# Teardown template

Fill one per game. Mark each line **[data]** (script/API), **[obs]** (played or screenshot), **[src]** (wiki, devforum, article: link it) or **[inf]** (your inference). Keep inferences labelled.

## 1. Snapshot
- Name, link, creator, genre, age, max players
- Playing / visits / visits per day (lifetime and recent) / favorites per 1k / like %
- Charts it appears in, with rank and date
- Last update, update cadence (from update notes or snapshots)

## 2. The promise (outside the game)
- Icon: subject, emotion, colors, text
- Thumbnails: what moment they show
- Title formula (e.g. "[Verb] a [Noun]", update tag in brackets, emoji)
- Description: first line, "How to play" list, notify/group prompts
- One-sentence pitch as a player would say it

## 3. First 60 seconds (from the observation sheet)
| Time | What happened | Purpose (inferred) |
|---|---|---|
| 0–5 s | | |
| ... | | |
- Time to control, to first verb, to first reward, to first upgrade
- How the game guided the player (arrows, beams, quest pill, NPC, text)
- First offer or purchase prompt: when and what

## 4. Loops
```
Core:    action → result → reward → investment → better action
Meta:    ...
Social:  ...
Session: what ends a session and what brings them back
```
- The verb, and how it feels (feedback, juice)
- Progression: what grows, how fast, where it slows (rebirth? zones?)
- Economy: currencies, sources, sinks

## 5. Social and viral drivers
- What makes players bring friends (needed for a mechanic, shared goals, competition)
- What makes moments shareable (chaos, rare drops, stealing drama, transformation, scale)
- Interaction with strangers (steal, trade, fight, help)
- Live events, update countdowns, notify prompts, group rewards

## 6. Retention hooks
- Timers (growth, offline earnings, daily rewards, streaks)
- Collections, rarity and show-off
- Long-term goals visible early
- Update cadence and events

## 7. Monetization map
- Game passes: name, price, type (from `--passes`)
- Developer products seen in-game: currency packs (tiers and prices), boosts (duration, price), spins/eggs (odds shown?), skips, revives, gifts
- Starter pack / limited offers / subscriptions / private servers
- Where offers appear (shop button, contextual prompts, popups, after failure, after success)
- What free players can and can't do

## 8. What made it different
The one or two things that separate this game from others with the same loop. Be specific ("you can steal other players' eggs while they're AFK, and they see it happen" not "good social features").

## 9. Weaknesses and gaps
Player complaints, missing features, performance issues on phones, unserved audiences, stale content.

## Observation sheet (for the user's play session)

Ask the user to play the first 10–15 minutes as a new player (a fresh alt account shows the real new-player flow), on a phone if possible, and note:

```
Game:                      Device:                 Date/time:
Loading → in control (s):
First thing I saw:
First thing I did (and at what second):
First reward (s), what it was:
First upgrade/purchase with in-game currency (s):
First time I felt "oh, that's cool":
First time I was confused:
Text/tutorial popups (count, how long):
First Robux offer (s), what it was, how it was shown:
Shop contents and prices (screenshot):
Other players: what were they doing, did they interact with me?
What the long-term goal seemed to be:
What would bring me back tomorrow:
Server size / how full:
```

Screenshots of the spawn view, the HUD, the shop, and any popup are worth more than notes.
